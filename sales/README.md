# sales/ — Sales Strategy, Funnels & Partnerships

**Owner:** `sales-manager`

## What belongs here
Sales strategy · customer journeys · funnels · lead generation · outreach scripts · follow-up sequences · offers and bundles · partnership strategy · pipeline structure · weekly sales reports.

## Structure
```
sales/
├── journeys/       ← how each segment goes from stranger to subscriber
├── funnels/
├── outreach/       ← scripts for schools, camps, co-ops, dive shops
├── sequences/      ← email and follow-up sequences
├── offers/
├── partnerships/
└── reports/        ← weekly sales report + forecast
```

## The rules for this folder
1. **Nothing here has been sent.** Every script and sequence is a draft.
2. **Actual sales, estimates, and goals are never mixed** — every report separates them visibly.
3. **No price appears here** until Finance has checked the margin and Maya has approved it.
4. **No customer names or contact details** in any file.
