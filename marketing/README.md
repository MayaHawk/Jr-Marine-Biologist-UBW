# marketing/ — Social Media & Content

**Owner:** `social-media-manager`

## What belongs here
Platform strategy · content calendars · written posts, captions, hooks and scripts · topic campaigns · the metrics tracker.

## Structure
```
marketing/
├── strategy/     ← which platforms, and why
├── calendars/    ← monthly and weekly plans
├── campaigns/    ← per-topic campaigns (sharks, sea turtles...)
├── content/      ← the actual written posts, by month
└── metrics-tracking.md
```

## The rule for this folder
**Nothing here has been published.** Every file is a draft awaiting Maya's approval. No invented testimonials, reviews, follower counts, or engagement numbers. No price, discount, or date Maya hasn't confirmed.
