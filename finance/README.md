# finance/ — Bookkeeping, Costs & Financial Planning

**Owner:** `finance-manager`

> ⚠️ **Everything in this folder is internal planning only. It is not tax, accounting, or legal advice. It is designed to be reviewed by a licensed CPA or bookkeeper.**

## What belongs here
Chart of accounts · COGS per kit · unit economics · break-even · budgets · cash flow forecasts · pricing analysis · the dashboard · the list of information still needed.

## Structure
```
finance/
├── cogs/       ← what each kit actually costs to make and ship
├── budgets/    ← one file per month
├── pricing/    ← pricing analysis per product
└── (top-level: unit-economics, break-even, cash-flow-forecast, dashboard,
     chart-of-accounts, monthly-vs-annual-analysis, information-needed)
```

## The rule for this folder
**A made-up number here is worse than no number**, because Maya might spend real money on it. Every figure is CONFIRMED, ASSUMPTION, ESTIMATE, or NEEDS FOUNDER INPUT. Every calculation shows its formula and inputs.

No agent has access to QuickBooks, banking, or payment systems. This folder *designs* the structure; Maya or her bookkeeper implements it.
