Act as the **chief-of-staff**.

Prepare this week's founder briefing using `templates/weekly-founder-briefing.md`.

Save it as `tasks/briefing-YYYY-MM-DD.md` (today's date). **Do not overwrite the template.**

Include:
1. **Headline** — one sentence
2. **Decisions needed from Maya** — first, numbered, each with your recommendation
3. **Approvals requested** — what the team wants to send, publish, or spend
4. **What the team did**, with file links
5. **What's blocked**, and on which open question
6. **The numbers** — real data only; anything unknown reads NEEDS FOUNDER INPUT
7. **Next week's 3–5 priorities**
8. **Any disagreements** — both positions, the trade-off, your recommendation, Maya decides

Under one page. If Maya has to hunt for the decision, rewrite it.
