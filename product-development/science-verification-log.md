## Standing rules for this file

1. **If a fact is not certain, it does not go on a card.** It goes here.
2. **A number on a card is a claim.** Lengths, dates, population figures and percentages all need a source or an explicit "this is a simplified model" label.
3. **A vocabulary word must be defined in plain language on the same card** that uses it.
4. Extinct species are never listed alongside living ones without saying so.
5. A group name (hammerhead, mako) is not a species. If a specific animal is meant, name it.
6. ❌ **No educational standard is claimed anywhere.** The team may write *"supports hands-on learning in life science and ecology."* It may never write that a kit meets NGSS, is aligned to any state standard, is accredited, counts for credit, or satisfies a homeschool requirement — **unless Maya has confirmed it in writing.**

## Added 2026-09-19 — the species flash cards (`DAHRRYxWM2o`)

### 🔴 SV-13 — Dwarf lanternshark length
**Claim as extracted:** "Lengths up to 4–5 feet"
**Concern:** the dwarf lanternshark is roughly **8 inches (20 cm)** — among the smallest sharks known. The card's own text calls it *"one of the smallest sharks in the world"*, so a 4–5 ft figure would contradict the same card by about six times.
**Caveat:** Canva returned text elements out of visual order, so the figure may belong to the adjacent **leopard shark**, which genuinely is 4–5 ft.
**Why it matters:** the Math activity orders these cards smallest to largest against a measured line. A wrong length teaches wrong ordering, and a number printed on a card is read as fact by a teacher.
**Verifier:** Maya. **Status:** ⬜ VERIFY

### 🟡 SV-14 — Giant sawfish classified as a shark
**Claim:** Giant Sawfish appears in a set of shark flash cards.
**Concern:** sawfish are **batoids (rays)**, not sharks — both are cartilaginous fish, but they are different groups. A card presenting one plainly as a shark would be inaccurate.
**Note:** this could become a strength rather than a correction — *"looks like a shark, actually a ray, here's how you tell"* is exactly the kind of real distinction this brand is built on.
**Verifier:** Maya. **Status:** ⬜ VERIFY
